# 로그 샘플

운영 로그(`logs/`)는 git에 올리지 않고, 형식 확인용 샘플만 둡니다.

- `requests_sample.jsonl`: app.py 가 남기는 요청 로그 예시 (추천 3건, 클릭 2건, 예측 1건).
  실제 API에 요청을 보내 만든 로그입니다.
- `recommend_labels_sample.csv`: 위 로그에 `03_collect_labels.py` 를 돌린 결과입니다.
  **판매 여부는 시뮬레이션입니다.** 추천 다음 날 크롤링에서 추천 매물 3건은 목록에서
  사라지고 1건은 판매완료가 됐다고 가정해 만든 값이라, 판매율 숫자에는 의미가 없습니다.
  정답이 어떤 형태로 붙는지만 보여 주는 용도입니다.
